# Legacy Tkinter prototypes

The original desktop (Tkinter) versions of the ACEest app, kept for reference.
Their business logic was ported to the Flask service in `aceest/`.

| Version | Features introduced |
|---|---|
| 1.0 | Static programme catalogue (Fat Loss, Muscle Gain, Beginner) |
| 1.1 / 1.1.2 | Calorie estimation, charts, CSV export |
| 2.0.1 / 2.1.2 | SQLite persistence for clients and weekly progress |
| 2.2.1 / 2.2.4 / 3.0.1 | Adherence charts, BMI & risk info, workout logging |
| 3.1.2 / 3.2.4 | Login & roles, workouts/exercises/metrics, random programme generator, PDF reports, membership |

These files are not part of the build and are excluded from linting.
